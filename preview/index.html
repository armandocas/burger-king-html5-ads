Production notes

BuildCopy lives in creative.json. The build writes six HTML5 ZIPs from one HTML and JS source, with CSS rules for each canvas size.
DeliveryFive files per ZIP: HTML, CSS, JS, PNG, and SVG. Backups are separate PNGs. The largest uncompressed unit is under 36 KiB.
QAAll six units passed dimension, asset, clickTag, keyboard, and reduced-motion checks. Layouts were reviewed in Chrome and Safari.
